tabsdata.tableframe.functions.lit

lit(
value: Any,
dtype: Boolean | Categorical | Date | Datetime | Decimal | Duration | Enum | Float16 | Float32 | Float64 | Int8 | Int16 | Int64 | Int32 | Int128 | Null | String | Time | UInt8 | UInt16 | UInt32 | UInt64 | None = None,
*,
allow_object: bool = False,
) → Expr
Categories:

generation

Expression for the given literal value.

Parameters:

  • value – The literal value.

  • dtype – The data type of the literal value.

  • allow_object – Whether to allow object data type.

Example:

>>> import tabsdata as td
>>>
>>> tf: td.TableFrame ...
>>>
>>> tf.select(td.lit("Hi").alias("lit"), td.col("age").alias("Age"))
>>>

│ Hi   ┆ 15   │
│ Hi   ┆ 18   │
│ Hi   ┆ null │
└──────┴──────┘
