# Catalogs

Source: https://docs.tabsdata.com/tutorials/catalogs/

Tabsdata captures metadata about your data assets, which can be loaded into external catalogs for further processing and analysis. These catalogs are supported today, and more are planned.

-   [AWS Glue Catalog](https://docs.tabsdata.com/tutorials/catalogs/aws-glue)
-   [Unity Catalog](https://docs.tabsdata.com/tutorials/catalogs/unity-catalog)
