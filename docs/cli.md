Reference documentation for the [`tdk`](https://docs.tabsdata.com/cli/tdk) and [`tdkserver`](https://docs.tabsdata.com/cli/tdkserver) CLI.

## CLI Binary Overview

[`tdkserver`](https://docs.tabsdata.com/cli/tdkserver) is a Rust based binary that enables creating, starting, and stopping Tabsdata servers.

[`tdk`](https://docs.tabsdata.com/cli/tdk) enables communication with running tabsdata servers, allowing users to create and execute workflows
