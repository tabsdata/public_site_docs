StreamSrcDef

class 
class StreamSrcDef(
    type_: str,
    system: str,
    src_version: str,
    conn: Type[Conn],
    src: Type[S],
    cardinality: Callable[[S], int],
    plugin: Type[StreamSrcPlugin],
    publisher_src: Type[StreamStageSrc],
    explorer: Type[Explorer] | None,
    icon: str | None,
)

Categories: spi

Entry-point registration for a StreamSrc binding.

Registered via the tabsdatak.connectors entry point. Binds a StreamSrc config type to the StreamSrcPlugin that runs it.

Parameters​

#

parameter
type_str

Wire-stable identifier, unique across all plugins (e.g. "postgres-cdc", "kafka-topic-in").

#

parameter
systemstr

Human-readable name of the target system (e.g. "Apache Kafka"); shown by tdk connection types.

#

parameter
src_versionstr

Connector schema version.

#

parameter
connType[Conn]

Concrete Conn subclass the stream source binds to.

#

parameter
srcType[S]

Concrete StreamSrc subclass this binding registers.

#

parameter
cardinalityCallable[[S], int]

Callable returning the number of output slots src declares (e.g. lambda s: len(s.tables)).

#

parameter
pluginType[StreamSrcPlugin]

StreamSrcPlugin subclass implementing run.

#

parameter
publisher_srcType[StreamStageSrc]

StreamStageSrc subclass naming the hidden batch source that ingests this stream's staged manifests; use StreamStageSrc itself for the default behaviour.

#

parameter
explorerType[Explorer] | None

Optional Explorer for tooling.

#

parameter
iconstr | None

Path to the connector's icon relative to the tabsdatak namespace root, or None for none.
