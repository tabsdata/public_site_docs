SalesforceSrcConn

class 
class SalesforceSrcConn(
    credentials: CredentialsSpec,
    instance_url: InstanceUrlSpec | None = None,
    category: str | None = None,
    objects: ObjectsNameSpec | None = None,
    entity_whitelist: EntityWhitelistSpec | None = None,
    conn_cfg: CfgSpec | None = None,
)

Bases: Conn

Categories: source

Salesforce org connection used by SalesforceSrc / SalesforceReportSrc.

Registered on a collection; the runtime resolves it and hands it to the source at run time.

Parameters​

#

parameter
credentialsCredentialsSpec (SalesforceTokenCredentials)

SalesforceTokenCredentials (username + password + security token).

#

parameter
instance_urlInstanceUrlSpec | None (str | Secret | None)

Optional explicit instance URL; must be an https:// URL on a Salesforce domain (salesforce.com / force.com / cloudforce.com / salesforce-setup.com). Accepts a plain string or a Secret.

#

parameter
categorystr | None

Optional category hint for entity discovery; mutually exclusive with objects.

#

parameter
objectsObjectsNameSpec | None (list[str] | None)

Optional non-empty list of explicit Salesforce object API names (each 1-80 chars, starting with a letter, then letters / digits / single underscores, optionally ending __c or __r). Mutually exclusive with category.

#

parameter
entity_whitelistEntityWhitelistSpec | None (list[str] | None)

Optional list of regex patterns narrowing which objects the source considers.

#

parameter
conn_cfgCfgSpec | None (dict | None)

Optional connector config dict (see CfgSpec).
