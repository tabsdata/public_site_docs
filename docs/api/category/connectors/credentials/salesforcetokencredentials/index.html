SalesforceTokenCredentials

class 
class SalesforceTokenCredentials(
    username: Secret,
    password: Secret,
    security_token: Secret,
)

Bases: SalesforceCredentials

Categories: credentials

Salesforce username / password / security-token credentials.

The standard SOAP / REST credential triple. Each field accepts a plain string or a Secret; the plugin combines password and security_token in Salesforce's concatenated-secret format at login.

Parameters​

#

parameter
usernameSecret

Salesforce login username, e.g. "user@example.com".

#

parameter
passwordSecret

Salesforce login password.

#

parameter
security_tokenSecret

User-specific security token (reset from Salesforce setup > Reset My Security Token).
