# tdkserver

> Every tdkserver command, generated from the CLI itself.

Source: https://docs.tabsdata.com/cli/tdkserver/

`tdkserver` manages Tabsdata instances on Kubernetes clusters.

| Group | Commands |
| --- | --- |
| [Info](https://docs.tabsdata.com/cli/tdkserver/info/) | `license`, `release-notes`, `third-party` |
| [config](https://docs.tabsdata.com/cli/tdkserver/config/) | `check`, `get`, `put`, `view` |
| [venv](https://docs.tabsdata.com/cli/tdkserver/venv/) | `list`, `update` |

## Standalone commands

| Command | Description |
| --- | --- |
| [`about`](https://docs.tabsdata.com/cli/tdkserver/about) | Show build metadata and system information |
| [`assess`](https://docs.tabsdata.com/cli/tdkserver/assess) | Check whether a tabsdata instance can be created |
| [`banner`](https://docs.tabsdata.com/cli/tdkserver/banner) | Show Tabsdata banner |
| [`create`](https://docs.tabsdata.com/cli/tdkserver/create) | Create a tabsdata instance |
| [`delete`](https://docs.tabsdata.com/cli/tdkserver/delete) | Delete the resources of a tabsdata instance |
| [`help`](https://docs.tabsdata.com/cli/tdkserver/help) | Show the commands of tabsdata on kubernetes |
| [`init`](https://docs.tabsdata.com/cli/tdkserver/init) | Produce an editable input config folder for a tabsdata instance |
| [`inspect`](https://docs.tabsdata.com/cli/tdkserver/inspect) | Show the configuration and state of a tabsdata instance |
| [`list`](https://docs.tabsdata.com/cli/tdkserver/list) | List registered tabsdata instances |
| [`quickstart`](https://docs.tabsdata.com/cli/tdkserver/quickstart) | Initialize, create and start a tabsdata instance in one step |
| [`restart`](https://docs.tabsdata.com/cli/tdkserver/restart) | Restart a tabsdata instance |
| [`set`](https://docs.tabsdata.com/cli/tdkserver/set) | Set a session setting used when commands omit it |
| [`settings`](https://docs.tabsdata.com/cli/tdkserver/settings) | Show the tabsdata session settings |
| [`shell`](https://docs.tabsdata.com/cli/tdkserver/shell) | Open an interactive shell. The commands listed under it are entered at the shell prompt, not on the tdkserver command line. |
| [`start`](https://docs.tabsdata.com/cli/tdkserver/start) | Start a tabsdata instance |
| [`status`](https://docs.tabsdata.com/cli/tdkserver/status) | Show the running workloads of a tabsdata instance |
| [`stop`](https://docs.tabsdata.com/cli/tdkserver/stop) | Stop a tabsdata instance |
| [`stubs`](https://docs.tabsdata.com/cli/tdkserver/stubs) | Copy the configuration stubs for '--config', and the project secrets stub, into the tabsdata home folder |
| [`trash`](https://docs.tabsdata.com/cli/tdkserver/trash) | Trash a local kminus tabsdata instance |
| [`unset`](https://docs.tabsdata.com/cli/tdkserver/unset) | Unset a session setting |
| [`upgrade`](https://docs.tabsdata.com/cli/tdkserver/upgrade) | Upgrade a tabsdata instance to the running tabsdata version |
