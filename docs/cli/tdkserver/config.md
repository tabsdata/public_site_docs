# tdkserver config

> config commands for the tdkserver CLI.

Source: https://docs.tabsdata.com/cli/tdkserver/config/

| Command | Description |
| --- | --- |
| [`check`](https://docs.tabsdata.com/cli/tdkserver/config/check) | Check the values still to be provided in the configs of a tabsdata instance |
| [`get`](https://docs.tabsdata.com/cli/tdkserver/config/get) | Download the configmaps of a tabsdata instance for editing |
| [`put`](https://docs.tabsdata.com/cli/tdkserver/config/put) | Replace the configmaps of a tabsdata instance from edited files |
| [`view`](https://docs.tabsdata.com/cli/tdkserver/config/view) | View the configmaps of a tabsdata instance |
