# tdkserver info

> Info commands for the tdkserver CLI.

Source: https://docs.tabsdata.com/cli/tdkserver/info/

| Command | Description |
| --- | --- |
| [`license`](https://docs.tabsdata.com/cli/tdkserver/info/license) | Show the license of tabsdata |
| [`release-notes`](https://docs.tabsdata.com/cli/tdkserver/info/release-notes) | Show the release notes of the current version of tabsdata |
| [`third-party`](https://docs.tabsdata.com/cli/tdkserver/info/third-party) | Show the third-party dependencies of tabsdata |
