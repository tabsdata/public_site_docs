# tdk fn trigger

> Trigger a function execution. It waits for the execution to finish with

Source: https://docs.tabsdata.com/cli/tdk/fn/trigger

Trigger a function execution. It waits for the execution to finish with

'--wait' and returns at once with '--no-wait'; with neither, the 'tdk set --trigger-wait true|false' setting decides (default: true).

```bash
tdk fn trigger \
  --proj quickstart \
  --format table \
  --name read_world \
  --coll <function pinned.<locals>.default at 0x10b614d60> \
  --plan-name my_plan* \
  --wait \
  --timeout timeout-example \
  --profile production
```

| Flag | Type | Required | Description |
| --- | --- | --- | --- |
| `--proj, -P` | string | Optional | Project to target; overrides the pinned project. Prompted for when a command needs one and neither is set. |
| `-o, --format` | table \| json \| yaml | Optional | Output format. 'json' and 'yaml' give a listing as an array and table data as one object per row. |
| `--name, -n` | string | Required | Name of the function to be triggered. |
| `--coll, -c` | string | Optional | Name of the collection to which the function belongs. Defaults to `<function pinned.<locals>.default at 0x10b614d60>`. |
| `--plan-name` | string | Optional | Name to be given to the plan that will be generated by the trigger. |
| `--wait, --no-wait` | flag | Optional | Wait until the plan reaches a final status, or return as soon as it starts. Exits 7 when '--timeout' runs out and 8 when a function run did not succeed. Default: the 'tdk set --trigger-wait' setting (true). |
| `--timeout` | string | Optional | Stop waiting after S seconds. Default: no limit. |
| `--profile` | string | Optional | Profile whose login and pinned project and collection this command uses; with no NAME, the default profile. Default: the profile set with 'tdk set --profile', else the default profile. |
