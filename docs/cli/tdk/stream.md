# tdk stream

> Streams commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/stream/

| Command | Description |
| --- | --- |
| [`disable`](https://docs.tabsdata.com/cli/tdk/stream/disable) | Disable a stream-publisher function |
| [`enable`](https://docs.tabsdata.com/cli/tdk/stream/enable) | Enable a stream-publisher function |
| [`list`](https://docs.tabsdata.com/cli/tdk/stream/list) | List the stream publishers of the project |
| [`plans`](https://docs.tabsdata.com/cli/tdk/stream/plans) | List the execution plans the stream publishers started, newest first |
