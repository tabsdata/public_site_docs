# tdk cron

> Crons commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/cron/

| Command | Description |
| --- | --- |
| [`disable`](https://docs.tabsdata.com/cli/tdk/cron/disable) | Disable a cron-triggered function |
| [`enable`](https://docs.tabsdata.com/cli/tdk/cron/enable) | Enable a cron-triggered function |
| [`list`](https://docs.tabsdata.com/cli/tdk/cron/list) | List the cron triggers of the project |
| [`plans`](https://docs.tabsdata.com/cli/tdk/cron/plans) | List the execution plans the cron triggers started, newest first |
