# tdk docs

> docs commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/docs/

| Command | Description |
| --- | --- |
| [`list`](https://docs.tabsdata.com/cli/tdk/docs/list) | List the documented symbols |
| [`search`](https://docs.tabsdata.com/cli/tdk/docs/search) | Search symbol names, qualified names and summaries, best first |
| [`show`](https://docs.tabsdata.com/cli/tdk/docs/show) | Show the reference page of a symbol |
