# tdk fn

> Functions commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/fn/

| Command | Description |
| --- | --- |
| [`bundle`](https://docs.tabsdata.com/cli/tdk/fn/bundle) | Download the bundle of a function version as a tar.zst archive. |
| [`delete`](https://docs.tabsdata.com/cli/tdk/fn/delete) | Delete a function |
| [`disable`](https://docs.tabsdata.com/cli/tdk/fn/disable) | Disables a function |
| [`enable`](https://docs.tabsdata.com/cli/tdk/fn/enable) | Enables a function |
| [`get`](https://docs.tabsdata.com/cli/tdk/fn/get) | Display a function |
| [`list`](https://docs.tabsdata.com/cli/tdk/fn/list) | List all functions in a collection |
| [`patch`](https://docs.tabsdata.com/cli/tdk/fn/patch) | Register a code-only patch of a function version. |
| [`patches`](https://docs.tabsdata.com/cli/tdk/fn/patches) | List patch versions of a function (latest first). |
| [`register`](https://docs.tabsdata.com/cli/tdk/fn/register) | Register a function. |
| [`trigger`](https://docs.tabsdata.com/cli/tdk/fn/trigger) | Trigger a function |
| [`update`](https://docs.tabsdata.com/cli/tdk/fn/update) | Update a function. |
