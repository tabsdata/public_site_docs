# tdk info

> Info commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/info/

| Command | Description |
| --- | --- |
| [`license`](https://docs.tabsdata.com/cli/tdk/info/license) | Show the license of tabsdata. |
| [`release-notes`](https://docs.tabsdata.com/cli/tdk/info/release-notes) | Show the release notes of the current version of tabsdata. |
| [`third-party`](https://docs.tabsdata.com/cli/tdk/info/third-party) | Show the third-party dependencies of tabsdata. |
