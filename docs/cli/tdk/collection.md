# tdk collection

> Collections commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/collection/

| Command | Description |
| --- | --- |
| [`connection`](https://docs.tabsdata.com/cli/tdk/collection/connection) | Display the connection of a source/destination collection. |
| [`create`](https://docs.tabsdata.com/cli/tdk/collection/create) | Create a new collection |
| [`delete`](https://docs.tabsdata.com/cli/tdk/collection/delete) | Delete a collection by name |
| [`get`](https://docs.tabsdata.com/cli/tdk/collection/get) | Display a collection by name |
| [`list`](https://docs.tabsdata.com/cli/tdk/collection/list) | List all collections |
| [`update`](https://docs.tabsdata.com/cli/tdk/collection/update) | Update a collection by name |
