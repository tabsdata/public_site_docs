# tdk auth

> Auth commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/auth/

| Command | Description |
| --- | --- |
| [`add-cert`](https://docs.tabsdata.com/cli/tdk/auth/add-cert) | Add a certificate for a Tabsdata Server. |
| [`delete-cert`](https://docs.tabsdata.com/cli/tdk/auth/delete-cert) | Delete a certificate for a Tabsdata Server |
| [`info`](https://docs.tabsdata.com/cli/tdk/auth/info) | Display information of the currently authenticated user |
| [`password-change`](https://docs.tabsdata.com/cli/tdk/auth/password-change) | Change the password of a user in a Tabsdata Server |
| [`service-token-create`](https://docs.tabsdata.com/cli/tdk/auth/service-token-create) | Create a service token in one of your two slots. |
| [`service-token-list`](https://docs.tabsdata.com/cli/tdk/auth/service-token-list) | List your service tokens. |
| [`service-token-revoke`](https://docs.tabsdata.com/cli/tdk/auth/service-token-revoke) | Revoke the service token in one of your slots. |
