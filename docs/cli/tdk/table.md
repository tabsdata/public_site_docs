# tdk table

> Tables commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/table/

| Command | Description |
| --- | --- |
| [`data`](https://docs.tabsdata.com/cli/tdk/table/data) | Show rows of data from the table |
| [`delete`](https://docs.tabsdata.com/cli/tdk/table/delete) | Delete a table |
| [`diff`](https://docs.tabsdata.com/cli/tdk/table/diff) | Show how a table's schema changed, or how it differs from another's. |
| [`download`](https://docs.tabsdata.com/cli/tdk/table/download) | Download the table as a parquet file |
| [`flow`](https://docs.tabsdata.com/cli/tdk/table/flow) | Show the functions and tables upstream and downstream of a table |
| [`list`](https://docs.tabsdata.com/cli/tdk/table/list) | List the tables of a collection, or of the whole project |
| [`profile`](https://docs.tabsdata.com/cli/tdk/table/profile) | Show per-column null rates, distinct counts and ranges of a table. |
| [`schema`](https://docs.tabsdata.com/cli/tdk/table/schema) | Show table schema |
| [`stats`](https://docs.tabsdata.com/cli/tdk/table/stats) | Show the size and schema of a table |
| [`tag-delete`](https://docs.tabsdata.com/cli/tdk/table/tag-delete) | Remove a user tag |
| [`tag-list`](https://docs.tabsdata.com/cli/tdk/table/tag-list) | List the tags, system and user |
| [`tag-set`](https://docs.tabsdata.com/cli/tdk/table/tag-set) | Set a user tag, replacing its value if the key is set |
| [`versions`](https://docs.tabsdata.com/cli/tdk/table/versions) | List the committed versions of the data of a table, newest first; the |
