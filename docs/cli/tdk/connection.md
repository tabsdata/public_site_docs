# tdk connection

> Connections commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/connection/

| Command | Description |
| --- | --- |
| [`check`](https://docs.tabsdata.com/cli/tdk/connection/check) | Check that a collection's connection connects, as a server-side probe. |
| [`entities`](https://docs.tabsdata.com/cli/tdk/connection/entities) | List the entities the last refresh of a collection's connection found. |
| [`get`](https://docs.tabsdata.com/cli/tdk/connection/get) | Display the catalog of a collection's connection: probe status, schema |
| [`list`](https://docs.tabsdata.com/cli/tdk/connection/list) | List the connections of source and destination collections |
| [`probe`](https://docs.tabsdata.com/cli/tdk/connection/probe) | Display a connection probe |
| [`refresh`](https://docs.tabsdata.com/cli/tdk/connection/refresh) | Explore a collection's connection again, as a server-side probe, and |
| [`sample`](https://docs.tabsdata.com/cli/tdk/connection/sample) | Read sample rows of a catalog entity, as a server-side probe. The rows |
| [`template`](https://docs.tabsdata.com/cli/tdk/connection/template) | Print a fill-in connection template for a connector type |
| [`types`](https://docs.tabsdata.com/cli/tdk/connection/types) | List the connection types available from installed connectors |
| [`validate`](https://docs.tabsdata.com/cli/tdk/connection/validate) | Validate a connection YAML document against its connector schema |
