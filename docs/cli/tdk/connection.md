# tdk connection

> Connections commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/connection/

| Command | Description |
| --- | --- |
| [`template`](https://docs.tabsdata.com/cli/tdk/connection/template) | Print a fill-in connection template for a connector type |
| [`types`](https://docs.tabsdata.com/cli/tdk/connection/types) | List the connection types available from installed connectors |
| [`validate`](https://docs.tabsdata.com/cli/tdk/connection/validate) | Validate a connection YAML document against its connector schema |
