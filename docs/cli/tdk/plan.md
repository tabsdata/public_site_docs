# tdk plan

> Plans commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/plan/

| Command | Description |
| --- | --- |
| [`cancel`](https://docs.tabsdata.com/cli/tdk/plan/cancel) | Cancel a plan: every non-committed transaction in it is canceled. |
| [`get`](https://docs.tabsdata.com/cli/tdk/plan/get) | Display a plan: its details plus its function runs and workers. |
| [`list`](https://docs.tabsdata.com/cli/tdk/plan/list) | List plans across every project you can view. |
| [`logs`](https://docs.tabsdata.com/cli/tdk/plan/logs) | Show logs of one of the plan's workers; when several ran, pick one from |
| [`monitor`](https://docs.tabsdata.com/cli/tdk/plan/monitor) | Monitor the execution of a plan. |
| [`recover`](https://docs.tabsdata.com/cli/tdk/plan/recover) | Recover a plan: its failed or on-hold function runs are re-scheduled, |
