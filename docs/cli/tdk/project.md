# tdk project

> Projects commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/project/

| Command | Description |
| --- | --- |
| [`create`](https://docs.tabsdata.com/cli/tdk/project/create) | Create a new project |
| [`delete`](https://docs.tabsdata.com/cli/tdk/project/delete) | Delete a project by name. |
| [`get`](https://docs.tabsdata.com/cli/tdk/project/get) | Display a project by name |
| [`graph`](https://docs.tabsdata.com/cli/tdk/project/graph) | Show the project's functions and tables and the edges between them |
| [`list`](https://docs.tabsdata.com/cli/tdk/project/list) | List all projects |
| [`secrets`](https://docs.tabsdata.com/cli/tdk/project/secrets) | List the secrets of a project, with their keys (never their values) |
| [`tag-delete`](https://docs.tabsdata.com/cli/tdk/project/tag-delete) | Remove a user tag |
| [`tag-keys`](https://docs.tabsdata.com/cli/tdk/project/tag-keys) | List the tag keys open on the project's entities |
| [`tag-list`](https://docs.tabsdata.com/cli/tdk/project/tag-list) | List the tags, system and user |
| [`tag-set`](https://docs.tabsdata.com/cli/tdk/project/tag-set) | Set a user tag, replacing its value if the key is set |
| [`tag-values`](https://docs.tabsdata.com/cli/tdk/project/tag-values) | List the values a tag key is open with on the project's entities |
| [`topology-list`](https://docs.tabsdata.com/cli/tdk/project/topology-list) | List the project's topology versions, each with when it was current |
| [`update`](https://docs.tabsdata.com/cli/tdk/project/update) | Update a project by name |
