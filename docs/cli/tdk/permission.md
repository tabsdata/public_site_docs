# tdk permission

> Permissions commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/permission/

| Command | Description |
| --- | --- |
| [`grant`](https://docs.tabsdata.com/cli/tdk/permission/grant) | Grant a permission to a user |
| [`list`](https://docs.tabsdata.com/cli/tdk/permission/list) | List a user's permissions, or who has access to a project |
| [`revoke`](https://docs.tabsdata.com/cli/tdk/permission/revoke) | Revoke a permission from a user |
