# tdk examples

> Examples commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/examples/

| Command | Description |
| --- | --- |
| [`extract`](https://docs.tabsdata.com/cli/tdk/examples/extract) | Extract an example into a directory |
| [`list`](https://docs.tabsdata.com/cli/tdk/examples/list) | List the bundled examples, optionally filtered |
| [`path`](https://docs.tabsdata.com/cli/tdk/examples/path) | Print the absolute path of the examples directory, or of one example |
| [`scaffold`](https://docs.tabsdata.com/cli/tdk/examples/scaffold) | Write the skeleton of a publisher, transformer or subscriber. |
| [`show`](https://docs.tabsdata.com/cli/tdk/examples/show) | Print an example: the source of a snippet, or the README and function |
