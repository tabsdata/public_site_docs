# tdk group

> Groups commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/group/

| Command | Description |
| --- | --- |
| [`create`](https://docs.tabsdata.com/cli/tdk/group/create) | Create a new group |
| [`delete`](https://docs.tabsdata.com/cli/tdk/group/delete) | Delete a group by name. System groups cannot be deleted. |
| [`get`](https://docs.tabsdata.com/cli/tdk/group/get) | Display a group by name |
| [`list`](https://docs.tabsdata.com/cli/tdk/group/list) | List all groups |
| [`update`](https://docs.tabsdata.com/cli/tdk/group/update) | Update a group by name. System groups cannot be updated. |
