# tdk user

> Users commands for the tdk CLI.

Source: https://docs.tabsdata.com/cli/tdk/user/

| Command | Description |
| --- | --- |
| [`create`](https://docs.tabsdata.com/cli/tdk/user/create) | Create a new user |
| [`delete`](https://docs.tabsdata.com/cli/tdk/user/delete) | Delete a user by name |
| [`get`](https://docs.tabsdata.com/cli/tdk/user/get) | Display a user by name |
| [`list`](https://docs.tabsdata.com/cli/tdk/user/list) | List all users |
| [`update`](https://docs.tabsdata.com/cli/tdk/user/update) | Update a user by name |
