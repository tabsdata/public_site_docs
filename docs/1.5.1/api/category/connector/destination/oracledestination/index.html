OracleDestination

classView source ↗
class OracleDestination(
    uri: str,
    destination_table: List[str] | str,
    credentials: UserPasswordCredentials = None,
    if_table_exists: IfTableExistStrategySpec = 'append',
)

Bases: DestinationPlugin

Categories: destination

Class for managing the configuration of Oracle-based data outputs.

Attributes: credentials (UserPasswordCredentials): The credentials required to access the Oracle database. destination_table (str | List[str]): The table(s) to create. If multiple tables are provided, they must be provided as a list. if_table_exists ({'append', 'replace'}): The strategy to follow when the table already exists.

  • ‘replace’ will create a new database table, overwriting an existing one.
  • ‘append’ will append to an existing table. uri (str): The URI of the database where the data is going to be stored.

Initializes the OracleDestination with the given URI and destination table, and optionally connection credentials.
