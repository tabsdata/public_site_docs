Delete a Group

Before you begin

Create a Group

Deleting a group deletes the collections inside it. Like the other deletes, it takes a typed confirmation.

Step 1Check what the group holds
tdk collection list --proj finance --group bronze

Every collection listed here goes with the group.

Step 2Delete it
tdk group delete \
  --proj finance \
  --name bronze

--confirm takes the literal string delete. The three system groups cannot be deleted, so this only ever applies to a group you created.

What deletion does​

The group's collections are deleted with it, along with their tables and functions. Functions in other collections that depended on those tables are frozen rather than deleted: they stay registered and stop running until they are re-registered against tables that exist.

See tdk group delete for the full option list.
