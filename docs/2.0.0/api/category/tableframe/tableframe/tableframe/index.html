TableFrame

class 
class TableFrame

Bases: EngineFrame

Categories: tableframe

A lazy, immutable tabular frame -- Tabsdata's wrapper over polars LazyFrame.

Every operation returns a new TableFrame without mutating the input. Instances arrive as arguments (and are returned) in @publisher / @transformer / @subscriber functions; build one directly with TableFrame.from_polars / from_pandas / from_dict / empty. Reference columns with col and constants with lit (both from tabsdatak.tableframe.functions).

Examples​

tf = TableFrame.from_dict({"g": ["x", "y", "x"], "v": [1, 2, 3]})
tf.filter(col("v") > 1).group_by("g").agg(col("v").sum().alias("total"))

grok
def grok(
    expr: str | Expr,
    pattern: str,
    schema: Mapping[str, ColumnDefinition],
) -> TableFrame

Parse unstructured text into columns with a Grok pattern.

Matches pattern against a string column and appends one column per named capture, keeping every existing column. A row whose text does not match gets null in each new column, so a bad line never fails the read. ColumnDefinition (from tabsdatak.tableframe.grok) names each new column and gives its data type.

Parameters:

#

parameter
exprstr | Expr

Name of the string column to parse, or an expression resolving to one.

#

parameter
patternstr

Grok pattern whose named captures (%{WORD:user}) become the new columns.

#

parameter
schemaMapping[str, ColumnDefinition]

Mapping of capture name to the ColumnDefinition describing the column it produces. A definition whose name differs from the capture renames the output column; its dtype is what the captured text is parsed into.

Returns:

A new TableFrame with one column added per capture.

Example:

tf.grok(
    "logs",
    r"%{WORD:user}-%{WORD:action}-%{INT:year}",
    {
        "user": ColumnDefinition("user", String),
        "action": ColumnDefinition("action", String),
        "year": ColumnDefinition("year", Int64),
    },
)

A definition can rename the capture, and the source column may be given as an expression:

tf.grok(
    col("logs"),
    r"%{WORD:user}-.*",
    {"user": ColumnDefinition("who", String)},
)

When a pattern repeats a capture name, the extra columns are disambiguated with a numeric suffix (field, field[1]).

Return the given columns of the row that ranks highest by them.

Each column is compared in its own natural order (numbers numerically, dates chronologically, strings alphabetically). The columns are ordered comparison keys: the first is primary, each subsequent one breaks ties on the previous. Returns None when the TableFrame is empty, unless fail_if_empty is set, in which case it fails.

Example:
